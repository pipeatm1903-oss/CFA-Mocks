# CFA Mock Exams 2026 — simulador Prometric

App web para hacer los 8 Mock Exams 2026 del CFA Level I con la interfaz del examen real y seguir la evolución en el Performance Tracker.

Las preguntas **no están en este repositorio**: se cargan una vez desde el archivo privado `mocks-cfa-2026.json` y se quedan guardadas solo en el navegador del ordenador.
